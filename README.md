# EDA-with-Excel
An analysis of the skills required in the data analytics industry as well as the salaries associated with those skills in different countries. The results were obtained using real-world data.
[Raw data can be viewed here]([data_jobs_salary_all.xlsx](https://github.com/user-attachments/files/33150317/data_jobs_salary_all.xlsx)
## Problems that were answered:
- What are the top skills in the data analytics industry?
- Does having more skills mean more money?
- What is the top 10 skills?
## Skills that were used in this exploratory data analysis
- Statistics
- Power query
- Pivot tables
- Power pivot
- Pivot charts
- DAX
## Challenges
- The data set was large and messy and required me to improve my skills in ETL processes.
- Using the correct DAX formulae pushed me to improve my skills and learn new ways in which DAX can be used.
